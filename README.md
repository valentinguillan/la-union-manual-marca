# La Unión · Manual de marca

Manual digital de La Unión, Panadería & Confitería de Tolhuin, Tierra del Fuego. Reúne criterios de identidad, color, tipografía, fotografía, voz y aplicaciones para dar continuidad a la marca.

## Contenido

- Diez secciones de consulta con navegación adaptable a computadora y celular.
- Referencias PANTONE 172, 7506 y 654, con rojo, beige y blanco protagonistas y azul de apoyo.
- Cuatro combinaciones de fondo y firma.
- Fotografías y aplicaciones ampliables.
- Manual editorial de 32 páginas en PDF, con créditos actualizados.

## Uso

Sitio estático en HTML, CSS y JavaScript. No requiere instalación de dependencias ni compilación. Se puede abrir `index.html` en un navegador o servir esta carpeta con un servidor estático.

El punto de entrada es `index.html` en la raíz del repositorio `valentinguillan/la-union-manual-marca`. La dirección de GitHub Pages es https://valentinguillan.github.io/la-union-manual-marca/. Todas las rutas son relativas y funcionan dentro de la subcarpeta del proyecto. El archivo `.nojekyll` permite servir los recursos estáticos directamente.

## Archivos

- `index.html`: capítulos y contenido del manual.
- `styles.css`: composición editorial y adaptación a pantallas.
- `app.js`: navegación, combinaciones de color y vistas ampliadas.
- `assets/`: firmas y recursos vectoriales, fotografías y PDF del manual.
